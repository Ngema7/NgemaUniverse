# 🌌 NGEMA UNIVERSE

A cinematic digital experience — the personal operating system of a Creative Technologist and AI Builder from Nepal.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📸 Add Your Photos

Place your three photos in the `/public` folder:
- `public/image.png`  — Main portrait
- `public/image1.png` — Secondary photo
- `public/image2.png` — Third photo

## 🛠 Tech Stack

- React + Vite
- GSAP + ScrollTrigger
- Framer Motion
- React Icons
- Vanilla CSS (no Tailwind)

## 📁 Structure

```
src/
  components/
    ui/          — Preloader, Navbar, CustomCursor
    sections/    — All page sections
    effects/     — StarField, KonamiEasterEgg
  styles/        — Global CSS
```
