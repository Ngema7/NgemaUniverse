## 🌌 About

**NGEMA UNIVERSE** is not just a portfolio. It is a **cinematic digital headquarters** that you explore like a universe: starfield backgrounds, orbiting skill nodes, a timeline-based origin story, and smooth cinematic transitions throughout.

Built by **Ngema Theeng**, a Creative Technologist and Full Stack MERN Developer from the hills of Sindhupalchok, Nepal, to show that world-class experiences can be built from anywhere.

> *"Every universe has a beginning. This is how one developer from the hills of Nepal set out to build the future."*

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18 or higher
- **npm** / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ngema-theeng/<repo-name>.git

# Enter the project
cd <repo-name>

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **http://localhost:5173** and explore the universe. 🌠

### Scripts

| Command | Action |
|---|---|
| `npm run dev` | Start dev server with hot reload |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build |

## ☁️ Deployment

Deployed on **Vercel** with zero configuration.

1. Push the repo to GitHub
2. Import it on [Vercel](https://vercel.com/new)
3. Preset: **Vite** · Build: `npm run build` · Output: `dist`
4. Click **Deploy** 🚀
